# Iris Flower Classification Using Decision Tree

## Project Overview
This project implements a Machine Learning model to classify Iris flowers into three species: Setosa, Versicolor, and Virginica using the Decision Tree Classification algorithm.

## Objectives
- Understand and implement Decision Tree Classification.
- Perform Exploratory Data Analysis (EDA).
- Train and test a Machine Learning model.
- Evaluate model performance using classification metrics.
- Predict the species of a new Iris flower.

## Dataset
The Iris dataset provided by Scikit-learn.

- Total samples: 150
- Features: 4
- Classes: 3

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Methodology
1. Dataset Loading
2. Exploratory Data Analysis
3. Data Preprocessing
4. Train-Test Split (80:20)
5. Decision Tree Model Training
6. Model Evaluation
7. New Flower Prediction

## Model Performance
- Algorithm: Decision Tree Classifier
- Accuracy: 96.67%
- Correct predictions: 29 out of 30 test samples

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Conclusion
The Decision Tree Classifier successfully classifies Iris flowers with an accuracy of 96.67%. The project demonstrates the practical implementation of supervised Machine Learning and model evaluation techniques.
